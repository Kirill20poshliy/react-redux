## Установка зависимостей
```bash
npm i
```

## Запуск приложения
```bash
npm start
```

Обоснование добавление Redux в проект:
- Контакты могут потребоваться в разных компонентах. При добавлении store не будет потребности в пробрасывании пропсов
- Отладка и отслеживание состояния при помощи Redux DevTools
- Добавление middleware для сложной логики
- Масштабируемость

Требуемые изменения в проекте:
- Добавить возможность полного CRUD взаимодействия с "сервером"
- Перевести проект на redux toolkit
